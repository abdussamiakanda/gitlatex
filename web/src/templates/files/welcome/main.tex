\section{Try the slash commands}\label{sec:slash}
Start a new line and type \texttt{/} to open the command menu. Try
\texttt{/table}, \texttt{/matrix}, \texttt{/image}, \texttt{/equation} or
\texttt{/cite}. The IDE inserts a ready-made template and adds any package it
needs to the preamble for you.

\begin{itemize}[leftmargin=2.4em, label=\textcolor{MidnightBlue}{$\blacktriangleright$}]
  \item \textbf{Beginners}: never memorise syntax again.
  \item \textbf{Experts}: full \TeX{} --- \verb|\makeatletter|, \verb|\dimexpr|,
        \verb|\ifcase|, any package from \TeX{} Live.
  \item \textbf{Everyone}: your files never leave your machine unless you push
        them to your own GitHub repository.
\end{itemize}

\section{Mathematics}
The Gaussian integral and a matrix, straight from \texttt{amsmath}:
\begin{equation}\label{eq:gauss}
  \int_{-\infty}^{\infty} e^{-x^2}\,\mathrm{d}x = \sqrt{\pi},
  \qquad
  A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}.
\end{equation}
Equation~\eqref{eq:gauss} is referenced automatically --- cross-references,
tables of contents and bibliographies are resolved with as many passes as
\TeX{} needs. Low-level primitives work too: $3\times 2\,\text{pt} + 1\,\text{pt}
= \the\dimexpr 3\dimexpr 2pt\relax + 1pt\relax$.
